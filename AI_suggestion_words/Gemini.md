# UniTrack+ Gemini AI 整合功能與架構規格 (Phase 2 儲備文檔)

本文檔統整 **UniTrack+** 應用程式中與 **Google Gemini AI** 相關之架構設計、API 調用規格、Prompt 提示詞工程與未來規劃。

> **狀態說明**：原 v1.3~v1.5 實驗性之「課表截圖辨識導入」於 v1.5.1 進行代碼精簡重構而暫時解耦，此文檔保留相關 Prompt 工程與資料規格，作為 Phase 2 重構與擴展「AI 課堂助理」之技術基準。

## 1. 課表照片智慧導入 (Timetable Image Parser)

### 📌 功能概述
允許使用者從**相簿選取**大學課表截圖／照片，由 Gemini 多模態視覺模型自動解析課表的二維網格結構，一鍵結構化匯入所有學期課程。

---

### 🧠 模型架構與調用優先級
* **主要模型**：`gemini-3.5-flash`
  * **超低延遲優化**：配置 `thinkingBudget: 0`，略過推論鏈延遲，實測回應速度達到 **~1.0 秒**。
* **第一備援**：`gemini-3.6-flash`
* **第二備援**：`gemini-flash-latest`

---

### ⚙️ 圖片前處理與傳輸優化
* **動態尺寸等比縮放**：長寬上限限制為 `1024px`，維持 OCR 銳利度同時大幅壓低 Base64 體積。
* **壓縮品質**：JPEG `75%`（傳輸封包自 1.5MB 縮減至約 **80~100KB**，大幅節省網路頻寬）。

---

### 📝 Prompt 提示詞設計規範

```text
請分析這張課表照片/圖片，仔細辨識其中的所有課程與上課時間資訊，並以 JSON 陣列格式輸出。

【重要原則】：
嚴格遵守「圖片中有提供的資訊才填寫，沒有提供的資訊絕對不要自行猜測或推斷填入」。
若圖片中未明確標記教師、教室、課程代碼、學分數、學分屬性或修別，請一律保持空白 ""、0.0 或 "UNSPECIFIED"，交由使用者日後自行選填。

每門課程物件欄位規格：
- "name": 課程名稱 (字串, 必填)
- "code": 課程代碼 (字串, 若圖片未提供填 "")
- "teacher": 授課教師姓名 (字串, 若圖片未提供填 "")
- "location": 教室或上課地點 (字串, 若圖片未提供填 "")
- "dayOfWeek": 星期幾 (整數: 1=星期一, 2=星期二, 3=星期三, 4=星期四, 5=星期五, 6=星期六, 7=星期日)
- "startPeriod": 開始節次 (整數 0..14。例如：第1節填1，第3節填3)
- "endPeriod": 結束節次 (整數 0..14。單節課填相同節次，若連續2節如3~4節則填4)
- "startTime": 上課開始時間 (字串格式 "HH:mm" 如 "08:10", "10:10" 等，若圖片有標註請依圖片填寫，若無請依節次推算)
- "endTime": 上課結束時間 (字串格式 "HH:mm" 如 "10:00", "12:00" 等)
- "credits": 學分數 (浮點數，若圖片有明確標記請依圖片填寫；若圖片未標記，請依該堂課的總節數 (endPeriod - startPeriod + 1) 自動推算填寫，例如 3~4 節為 2.0，6~8 節為 3.0)
- "category": 課程學分屬性 (字串，僅在圖片明確寫出通識/必修/選修/模組等屬性字眼時填寫，否則一律填 "UNSPECIFIED")
- "requirementType": 修別 (字串，僅在圖片明確寫出必修/選修/必選修時填寫，否則一律填 "UNSPECIFIED")
- "subcategory": 子分類 (字串, 若圖片未提供填 "")

特別注意：
1. 若同一門課在同一天連續上課（例如 3, 4 節），請合併為一筆資料，startPeriod=3, endPeriod=4。
2. 若同一門課在不同天（例如星期一與星期三），請拆分為多筆不同 dayOfWeek 的課程。
3. 請只輸出合法的 JSON Array，不要包含任何額外的解釋文字或 Markdown 外框。
```

---

### 🛡️ AI 辨識後處理與防護機制

1. **節次連續性自動合併**：
   - AI 自動將連續時段（如週一第 3、4 節）合併為單一課程記錄。
2. **學分智慧推算**：
   - 若圖片未載明學分，系統依 `(endPeriod - startPeriod + 1)` 自動賦予對應學分數（2 節 = 2.0 學分、3 節 = 3.0 學分）。
3. **時段衝突偵測 (Conflict Prevention)**：
   - 比對 Room 資料庫與批次清單，同星期且重疊節次之課程標記警示並防範重複排課。

## 2. Phase 2 規劃擴展：AI 課堂助理

* **課程筆記智慧摘要**：針對課堂隨堂筆記進行重點提煉與條列式摘要。
* **期末備考指南**：根據各科出席狀況、筆記重點與學分比重，生成個人化複習計畫。
